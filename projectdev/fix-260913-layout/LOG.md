# 页面高度与地图图例

用户报告库存底部被裁切、世界地图缺少字母与建筑功能对照。确认桌面外层与滑动面板固定 700px 并隐藏溢出，背包另有 660px 上限；图例此前没有实现。

修改：保留横向滑动宽度，观察当前内容并更新垂直高度；解除背包高度上限，菜单随文档滚动；增加本地化地图图例与探索迷雾说明，手机方向键位于地图与图例之间；补给栏适应宽度及内容高度；事件窗口在桌面和手机均固定于视口并使用统一遮罩。

复现：在隔离浏览器中使用用户存档的库存和技能数据，内容区增长到 790px，库存最底部位于 790px，容器底部为 810px。源存档未修改。首次布局回归还发现桌面缩至 320px 后补给栏保留 649px 内联宽度，已用紧凑布局宽度约束修复。

验证：新增浏览器测试覆盖短桌面视口的库存底部、滚动后弹窗、中文新地标图例、图例底部可达、重复计算无高度增长、320px 布局及桌面恢复、显示图例不改变迷雾。

最终结果：`npm.cmd test` 通过 12 项逻辑测试及内容校验；`npm.cmd run test:browser` 通过全部 16 项浏览器测试。已查看桌面地图图例和手机全页截图，并调整手机表格列宽以留出功能说明空间。未在实体 Android 设备实测。
