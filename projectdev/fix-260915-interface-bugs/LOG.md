# 新版本界面修复（1）

范围：开局地图符号过大、事件漏译、满背包拾取菜单快速跳动。沿用当前项目和存档结构，不修改用户浏览器中的实际存档。

地图原先将窗口宽度直接除以10作为开局字符宽度，导致符号放大。现在每个格子独立排版，字号为 `min(20px, 内容宽度 / max(30, 显示边长) / 0.6001)`；10、20、30格阶段字号固定，之后继续缩小。地图仍为正方形，坐标和迷雾规则不变。实际移动与最外圈检查发现字符会有少量边缘溢出，因此增加6像素留白，点击换算从第一个格子的实际位置开始。

汉化审计遍历全部脚本中的静态翻译调用及事件展示字段，发现双头怪物4条和彭罗斯幻象5条缺少译文。已补齐中文运行时字典、PO及翻译源JSON，并同步26份目录。内容验证从扩展事件扩大到所有事件文件，检查1240个中文文本引用。平台名称和纯格式占位串保留原样。

拾取按钮原先浮动排列，中文样式每个按钮占宽164像素，两列总宽328像素，335像素宽的弹窗出现滚动条后空间不足，第二列换行；鼠标因此反复进入/离开按钮。改为两列自适应网格，并预留滚动条空间。丢弃菜单在按钮内向下展开，长列表内部滚动，避免遮挡或裁掉末尾选项。保留现有拾取和丢弃的数量事务。

新增浏览器回归覆盖真实前五步、地图点击方向与61格边缘、桌面/360/280像素下连续45帧悬停稳定性、丢弃换物数量守恒、短视口触屏取消和最后一项换物、双头怪物战斗与幻象实际中文显示。

最终验证：`npm test` 24项逻辑测试通过，内容校验通过；`npx playwright test` 全部30项浏览器测试通过（新增6项）。实际查看开局地图及桌面、手机的满背包菜单截图：符号大小正常，两列稳定，菜单末尾与离开按钮均可到达。测试使用隔离浏览器上下文载入既有罗盘测试存档，没有覆盖用户正在游玩的存档。
