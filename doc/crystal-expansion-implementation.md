# 晶格远征扩展：实现与验证

本文于2026-10-04同步当前实现；维护状态与检查结果见 [项目当前状态](project-status.md)。最新中后期配方、仓库/要塞、动态地图和专长见 [frontier-update.md](frontier-update.md)。

本次实现依据 `crystal-expansion-development-plan.md` 的功能规格，采用两艘新船、三处工业遗址、三段晶格、两座工棚和100人口的建议默认值。存档版本提升至1.4。原有战舰三翼、指挥甲板首领、普通结局和舰队信标结局保留；线圈枪仍属后续可选内容。

## 运行与验证

这是直接加载 JavaScript 的静态网页项目，无需打包步骤。安装依赖后运行 `npm start`，打开 `http://localhost:8080/?lang=zh_cn`。

```sh
npm ci
npm test
npm run test:browser
```

`npm test` 运行 Node 逻辑测试和内容校验；浏览器测试使用 Playwright，在 Windows 默认使用已安装的 Edge。其他系统可先运行 `npx playwright install chromium`；也可通过环境变量 `PLAYWRIGHT_CHANNEL` 指定浏览器通道。

## 玩家流程

| 地标 | 符号 | 距村庄距离带 | 作用 |
|---|---|---|---|
| 废弃晶体厂 | K | 32–36 | 初始晶体、晶体工岗位 |
| 化学工场 | E | 38–42 | 晶体刻蚀能力 |
| 精密装配厂 | D | 45–49 | 最后一段晶格安装、工棚 |
| 坠毁侦察舰 | R | 55–65 | 航图路线选择、晶格碎片、半径12的地图照明 |
| 掩埋运输舰 | T | 75–90 | 电池架或货运升降机路线、晶格碎片 |
| 残破战舰 | X | 65–75 | 原有主线装置与第一块晶格碎片；首领信标仍为支线 |

侦察舰两条路线都通向碎片。运输舰的电池架路线提供12个能量电池；升降机路线需要战胜货舱哨兵，提供3个外星合金和3个电池，两条路线随后均通向航向室。必要碎片自动收入行囊、重量为0，不出现在丢弃换空间的菜单中。

探索中的地图、工业解锁和碎片来源属于临时远征状态，死亡后回退。出行背包与存档中的配装配置分离，途中刷新不会把未交付碎片写入永久库存；返村时碎片库存与来源记录一起提交。普通晶体沿用战利品、背包和返村回收逻辑。

每名晶体工每45秒消耗2熏肉、1钢、2煤，产出1晶体，沿用现有收入系统。每座工棚增加10人口，最多两座；成本依次为木材1000/1500、钢50/75、皮革100/150。住房损失会限制实际可摧毁的小屋数量，并在通知界面和保存之前回收超额岗位。

晶格每段消耗1碎片、4晶体、10钢、20硫磺、3电池、1外星合金；三段状态为暗淡、残缺、对齐、苏醒。加工需要制造器和化学工场，最后安装还需要精密装配厂。任何前提或材料不足均不扣库存；起飞同时要求舰体大于0及晶格完成，坠毁后保留晶格。

## 兼容与修复

激光步枪现可凭蓝图在制造台加工，成本为 40 晶体、40 钢、5 能量元件。蓝图只在战舰初次探索的制造器奖励房间获得，需拾取后安全带回；贸易站不出售该蓝图。外星合金和地图分布的评估见 `late-game-balance-review.md`，当前地标参数见 `world-landmark-settings.md`。

三处工业遗址的首次清理现在各有一场必经战斗：废弃晶体厂的晶屑巢兽（35 生命、5 伤害）、化学工场的沟渠潜伏兽（45 生命、6 伤害）、精密装配厂的披甲拾荒者（60 生命、8 伤害）。均每两秒攻击，基础命中率 80%；最后一处使用远程攻击。入口可直接离开；战胜敌人后进入原有奖励场景，安全返回村庄才永久解锁。已清理的旧存档保持原有完成标记。

晶体用于村庄制造和飞船晶格修复，没有探险中的主动消耗用途，因此不再显示于出发携带列表；旧的晶体携带选择在整备时清除，库存不变。探险中拾取的晶体仍占用背包并能带回村庄。

能量元件可以在制造台批量加工：25 晶体、25 钢、10 硫磺产出 25 个，要求化学工场的刻蚀能力，不需要蓝图或精密装配厂。材料消耗与成品增加在同一次库存保存中提交，缺料时不扣资源。该配方以可再生工业材料支持后期弹药供给；当前为初版数值。既有贸易途径继续保留：获得过能量元件并建有贸易站后，可以用 10 鳞片和 10 牙齿反复购买一个，也可从舰船和机械敌人处获取。

新地图逻辑坐标为 `[-45,45]`，村庄为 `[0,0]`，数组存储为91×91；旧地图保留原有尺寸。地形生成保持原有概率；新地图从距离范围内合法格子等概率抽样，包含范围上限，首周目261个地点，初始地标间距至少5格、两个地点均在0–10格内时为3格，多数量类型按象限分配；枚举失败后整图有限重试8次，仍失败则报错。旧存档不移动数组元素；升级时保留矿井、已访问标记、飞船和战舰状态，补入缺失的五处新地标。已完成战舰主线的1.3存档获得一次对应碎片补偿，重复加载不再次发放。

战斗修复包括：stim消耗与三秒到期、hypo库存及生命检查、护盾消耗一个电池并阻挡一击、不再转为治疗、制造数量上限、机械四足重复掉落键、战斗和事件切换时的状态及伤害计时器清理。保留stim原有10点生命代价、干扰器四秒眩晕和各武器弹药规则。另处理了缺失音频的静音回退，以及结局移除通知面板后的动画回调。

评分权重与继承配置改用物品ID；旧的周目库存数组仍按冻结的旧顺序读取。晶体按每单位5分计入本局资产；碎片和晶格不计分，晶体可继承，碎片与工业解锁不继承。

英文原文进入POT及全部现有PO目录；简体中文覆盖工业遗址、舰船与晶格、制造台与装备蓝图、战斗按钮、战舰三翼与指挥甲板剧情、扩展结局及手机操作标签。其他语言缺失或空字符串回退为英文。更新词条可运行 `npm run update:expansion-translations`，需要 Python Babel。词条源为 `lang/crystal-expansion-zh_cn.json` 和 `lang/expansion-interface-zh_cn.json`，更新时同时同步 PO 与网页实际加载的 `lang/zh_cn/strings.js`，包含已有空译文的补齐。

## 检查范围与限制

逻辑检查覆盖原点、四角、地图渲染尺寸、30个随机种子的地标数量／范围／间距与象限配额、有限失败、1.0／1.1真实加载路径和1.3幂等迁移、修复事务、混合住房、碎片重复领取、自动保存、六种工业发现顺序、收入、战斗药品和计时器、制造上限、评分与继承。

内容校验解析全部游戏脚本，检查重复对象键、地标字符、事件与场景引用、配方与战利品物品、武器弹药、碎片场景可达性和新事件文本的翻译提取。中文校验覆盖1240处文本引用、装备与蓝图的动态名称、PO与运行时词典一致性、占位符和结局换行。浏览器检查使用真实事件按钮和DOM，覆盖新游戏、工业和舰船两种路线、旧档重载、药品战斗、死亡回退、工棚建造、三段修复、起飞与坠毁、两种结局、语言回退及中文手机界面的实际显示。为缩短验证时间，测试会设置探索位置和阶段库存；结局测试从成功飞行的边界进入原有结局流程。

数值仍是首版默认值，尚未进行从零资源开始的长时间人工通关及经济曲线调优。简体中文以外的新文本等待人工翻译。新增开发依赖及锁文件已记录。2026-09-12的审计曾记录Express／qs依赖链两项中等风险；2026-10-04维护未重新进行联网依赖审计，该历史结果不作为当前漏洞结论。
