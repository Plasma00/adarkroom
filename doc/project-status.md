## 2026-10-04维护

修复1.0／1.1旧存档加载故障：补入沼泽的迁移发生在`World.init()`之前，当时半径仍为新地图默认值45，访问61×61旧地图会越界。`Engine.loadGame()`捕获异常后把载入状态重置为新游戏。现在迁移按旧地图实际尺寸临时设置半径，并用`finally`恢复原值。修复不重新生成旧地图。

新增两项经过实际`Engine.loadGame()`入口的逻辑回归，先确认原实现失败，再验证修复；另增真实浏览器1.1存档加载及二次刷新用例。检查资源、地标、雾区、技能、船体、沼泽唯一性与重复迁移。独立内存检查还覆盖缺失版本、1.2、1.3及异常时半径恢复。

文档同步包括：修正架构指南中的地图坐标、渲染方式、测试命令及手机入口；更新扩展说明的地标距离、生成规则和校验数量；给历史设计／评估标记时间语境，并由README链接本页。

## 本地运行

```powershell
Set-Location -LiteralPath 'D:\OneDrive - University of Virginia\Projects\adarkroom'
npm.cmd ci
npm.cmd start
```

打开`http://localhost:8080/?lang=zh_cn`。保持使用原来的主机名与端口，`localhost`和`127.0.0.1`对应不同的浏览器存档空间。另开终端运行`npm.cmd test`和`npm.cmd run test:browser`。Windows浏览器测试默认使用Edge；其他平台的配置说明见[实现说明](crystal-expansion-implementation.md)。
