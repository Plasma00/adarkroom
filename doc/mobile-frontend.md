# 手机浏览器适配

入口 `index.html` 已配置设备宽度视口，保留浏览器缩放。Android、其他触屏设备及宽度不超过 700 CSS 像素的窗口自动启用紧凑布局，不再跳转到 `mobileWarning.html`，也无需添加 `ignorebrowser=true`。

房间、村庄、工人、背包、制造台和资源区改为纵向排布。按钮及数量增减控件至少有 44 像素触摸区域，建造和制造成本直接显示，语言选择使用系统下拉框。事件窗口固定在可见视口内，长内容可单独滚动，输入框保持 16 像素字体。菜单随页面滚动，避免覆盖操作区。

地图下方方向键每次轻触移动一格；滚动页面不会触发原来的全屏滑动移动。飞船方向键支持长按，松手、取消触摸、切换页面或打开事件时停止移动。横屏飞行时操作键移到画面右侧。地图从10×10随已揭晓坐标展开到91×91；10、20、30格阶段保持相同字号（最多20像素），之后才继续缩小字形。每格独立居中，边缘留白，点击按内容区域换算。飞船整体缩放展示，仍使用原来的 700×700 坐标与碰撞计算。

拾取窗口使用固定两列显示物品与“带走”，不再依靠浮动按钮恰好塞入窗口。丢弃菜单在物品按钮内向下展开，过长时可滚动，弹窗预留滚动条宽度。鼠标悬停或触屏点击均可选择丢弃物资，取消后不更改数量。

世界地图下方提供紧凑的“符号—名称”图例，只列出探索中已经见到的类型，不提前暴露地标名称。地点进入视野或地图道具揭开迷雾后解锁相应图例，清理并转为前哨后仍保留原类型的记录。图例发现与地图探索使用同一远征存档：安全回村保留，死亡回退本次新增发现。手机方向键位于地图和图例之间。

出发前的行装按武器、补给、功能性装备分组。弹药、食物、药品和饮水位于补给组；护甲、火把、辉光石等位于功能性装备组。夜间模式覆盖事件窗口、存档输入框和按钮，仍可在弹窗打开时切回日间配色。

弹窗只对实际操作区（主页、飞船、方向键、菜单与外部链接）设置不可交互，避免反复修改包含数千格地图的整个内容树。地图由遮罩及点击锁保护；背景从辅助技术中隐藏，焦点进入对话框，关闭后恢复。支持时使用浏览器原生透明度动画，桌面预留页面滚动条位置；手机保留完整可用宽度。

实现主要集中在 `script/mobile.js` 和 `css/mobile.css`。`Engine.setActiveModule()` 在原有页面切换处同步显示状态；手机适配本身不改变游戏规则，当前中后期规则见 `frontier-update.md`。桌面保留横向分栏，`Engine.initLayout()` 观察内容变化，让当前页面高度适应背包、库存及地图图例；长内容通过整页滚动访问，菜单位于内容之后。桌面事件窗口也固定在当前视口内，滚动到页面底部仍可操作。

本地运行 `npm start` 后，在同一局域网的手机上访问 `http://电脑的局域网IP:8080/?lang=zh_cn`。这是静态前端更新，无须额外打包；将整个项目的 HTML、脚本、样式等文件一起提供给浏览器即可。浏览器或 WebView 需要启用 JavaScript 和本地存储。

验证命令：`npm test`、`npm run test:browser`。移动端用例使用 Chromium/Edge 的 Android 用户代理、移动视口和真实触摸事件模拟，覆盖 320/360 像素竖屏、800 像素横屏、工人和背包增减、制造成本、地图滚动与移动、弹窗与输入视口缩小、飞船长按和取消、结局、桌面布局恢复。尚未在实体 Android 手机或嵌入式 WebView 上实测。
